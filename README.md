# EternalBliss - Digital Wedding Planner 💍✨

Aplikasi web modern, elegan, dan interaktif untuk perencanaan pernikahan (*Digital Wedding Planner & PWA*). Didesain khusus dengan tema estetika **Champagne Blush & Gold** untuk calon pengantin.

---

## 🌸 Fitur Utama

- **Dashboard & Countdown Live**: Hitung mundur waktu akad/hari-H secara real-time dengan efek visual taburan kelopak mawar (*rose petals*).
- **Profil Calon Pengantin & Foto**: Kustomisasi nama pengantin, tanggal, ballroom/venue, plafon anggaran, serta upload foto pasangan (dengan kompresi Canvas otomatis).
- **Kalkulator Anggaran & Pengeluaran**: Manajemen pos biaya vendor, estimasi, biaya riil, status pembayaran (Belum Bayar, DP, Lunas).
- **Checklist Tugas & Timeline**: Manajemen milestone persiapan dari H-12 bulan hingga Hari-H.
- **Manajemen Vendor & Kontak PIC**: Rekap data vendor, nilai kontrak, DP, nomor WhatsApp PIC, dan integrasi chat langsung.
- **Buku Tamu & RSVP Interaktif**: Rekap jumlah tamu, estimasi pax, plotting meja, dan status konfirmasi kehadiran.
- **Interactive Seating Chart**: Visualisasi denah meja bundar untuk penataan tempat duduk tamu VIP & keluarga.
- **Kalkulator Porsi Katering**: Simulasi perhitungan rasio porsi buffet & gubukan (*food stall*) standar pernikahan Indonesia.
- **Seserahan & Hantaran Pengantin**: Pelacak status belanja kotak seserahan, jasa hias, PIC pembawa, dan sinkronisasi otomatis ke anggaran.
- **Rundown Acara Hari-H & Kontak Darurat**: Susunan acara menit per menit beserta kontak panitia pelaksana.
- **Dedicated Print / PDF Engine**: Cetak laporan resmi siap tanda tangan panitia & WO dalam format A4 portrait.
- **PWA (Progressive Web App)**: Akses offline dan dapat di-install langsung ke layar utama HP (Android/iOS) atau desktop.
- **Backup & Ekspor JSON**: Backup seluruh data aplikasi ke file JSON lokal kapan saja.

## 🚀 Cara Menjalankan Secara Lokal

1. Clone repositori:
   ```bash
   git clone https://github.com/MiftakhuSubkhan/EternalBliss-Digital-Wedding-Planner.git
   cd EternalBliss-Digital-Wedding-Planner
   ```

2. Jalankan server lokal:
   ```bash
   node server.js
   ```

3. Buka di browser:
   ```
   http://localhost:3000
   ```

## 🌐 Deployment (Vercel)

Proyek ini telah dikonfigurasi dengan `vercel.json` dan siap di-deploy secara instan ke [Vercel](https://vercel.com) tanpa langkah build tambahan (*Zero-Config Static Site*).
